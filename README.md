# Student Management System (MySQL)

## Project Description
The Student Management System is a database management project developed using MySQL. It is designed to store, manage, and retrieve student information efficiently.

This project contains 120 sample student records and performs various SQL operations to manage student data.

## Features
- Display all student records.
- Find students from a particular city.
- Sort students by marks in descending order.
- Count students in each city.
- Calculate average marks for each course.
- Display the top 10 students.
- Use LIMIT and OFFSET for pagination.
- Create a Courses table.
- Perform INNER JOIN between Students and Courses.
- Find students who have pending fees.
- Count students enrolled in each course.

## Technologies Used
- MySQL
- SQL

## Database Tables
1. Students
2. Courses

## Learning Outcomes
- Understanding SQL queries.
- Working with database tables.
- Using WHERE, ORDER BY and GROUP BY.
- Applying aggregate functions like COUNT() and AVG().
- Understanding INNER JOIN.
- Working with LIMIT and OFFSET.

## Purpose
This project is created for learning and practising SQL queries and database management concepts.
